# Tic-Tac-Toe

A simple Tic-Tac-Toe game made in Python.

## Features

* Two-player gameplay
* Win detection
* Tie detection
* Input validation
* Play Again option

## How to Run

1. Download the project files.
2. Open a terminal in the project folder.
3. Run:

python Tick-Tack-Toe.py
